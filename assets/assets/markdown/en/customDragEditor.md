## Custom Drag Table

![Custom drag table](resource:assets/markdown/en/customDragEditor.png)

Shows the drag function of a cartridge that uses the **CUSTOM** drag model: a series of **Mach number › drag coefficient (Cd)** pairs. This model replaces the standard G1/G7 drag functions entirely and gives a bullet-specific drag curve.

> **View only for now.** This screen is read-only — the only button is **Close**, and the fields can't be edited yet. Editing is planned for a later version.

When the table has data it lists the pairs sorted by Mach, ascending (up to 100 rows). An empty table is shown as blank 0.00 / 0.0000 fields.

---

### Where the data comes from

Custom drag data is typically obtained from manufacturer specifications, Doppler radar measurements or external ballistic software, and can arrive with a profile imported from a file.
