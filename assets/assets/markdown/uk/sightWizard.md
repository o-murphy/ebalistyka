## Новий приціл / Редагування прицілу

![Редактор прицілу](resource:assets/markdown/uk/sightWizard_overview.png)

Заповніть поля, щоб створити приціл або відредагувати приціл профілю. Екран відкривається, коли ви додаєте чи замінюєте приціл профілю або торкаєтесь олівця біля розділу **Приціл** на екрані «Профілі». Натисніть **ОК**, щоб зберегти, або **Скасувати**, щоб вийти без збереження; для збереження приціл має мати назву.

Зображення вгорі (**Зображення прицілу**) — заглушка для фото прицілу; зображення поки що не підтримуються. Воно не пов'язане із сіткою, яку обирають нижче.

---

### Загальне

- **Назва прицілу** — назва для ідентифікації цього прицілу (обов'язково)
- **Виробник** — назва виробника

---

### Кріплення

- **Висота прицілу** — відстань від осі каналу ствола до оптичної осі прицілу; впливає на розрахунок піднесення
- **Горизонтальне зміщення** — бічне зміщення прицілу від осі ствола; залиште 0 для центрального кріплення

---

### Сітка прицілу

- **Зображення сітки прицілу** — торкніться, щоб обрати зображення сітки, яке показується на екрані «Сітка прицілу»
- **FFP / SFP / LWIR** — фокальна площина: перша (FFP), друга (SFP) або тепловізійна (LWIR)
- **Мінімальна кратність / Максимальна кратність** — діапазон збільшення прицілу; разом із фокальною площиною використовується для правильного масштабування сітки

---

### Кліки

- **Вертикальний клік / Горизонтальний клік** — кутове значення одного кліка барабана по кожній осі; оберіть одиницю (MIL, MOA, …) поруч зі значенням
