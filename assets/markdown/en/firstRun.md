## Welcome to eBalistyka!

![icon](resource:assets/markdown/icon64.png)

eBalistyka is a ballistic calculator for precision shooting. It calculates scope adjustments based on your weapon, cartridge, and current conditions.

A sample profile is already set up, so you can see a result right away.

**To get started:**

1. Open the **Profiles** screen (tap the profile name at the top of Home) and set up **your** profile — weapon, cartridge and scope
2. Set the **conditions** — temperature, humidity, pressure, altitude, wind (the **Conditions** tab and the quick buttons on Home)
3. Read the **adjustments** on the home screen

Whenever you have a question about a screen, look for this button **?**:

![helpButton](resource:assets/markdown/helpButton.png)

> **Using the web version?** Your profiles and settings are stored in this browser only — make a backup from time to time in **Settings → Backup → Export**. You can install it as an app: desktop browsers offer **Install as app** (in Settings → About), on iPhone/iPad use Share → Add to Home Screen.

Good luck on the range!
