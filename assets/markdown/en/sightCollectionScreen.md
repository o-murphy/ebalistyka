## Scope Collection

![Scope collection](resource:assets/markdown/en/sightCollectionScreen_overview.png)

A built-in database of preset scopes. Tap the **check-mark button** (bottom-right of a card) to take that scope for the profile.

Each card shows:
- **Manufacturer** and **model name**
- **Reticle** pattern name (the reticle is drawn behind the card)
- **Vertical** and **horizontal click** values
- **Sight height** (mounting height above the bore)
- **Magnification** range

---

### Search

Type in the search field to filter by name or manufacturer. The list updates instantly.

---

### Filter

Tap the **filter** icon (top-right) to open the Filter sheet and narrow the list by:
- **Vendor**
- **Focal plane** — First (FFP) or Second (SFP)

**Apply** uses the filter, **Reset** clears it. A badge on the icon shows an active filter.
